# UrbanStyle Customer Data Cleaning

Python project focused on cleaning and preparing messy customer data for analysis using pandas.

## Features
- Handles missing values
- Fixes inconsistent data formats
- Converts data types (dates, currency, numeric)
- Standardizes names, categories, and phone numbers
- Removes duplicate records
- Creates new features for analysis
- Generates business insights

## Tech Stack
- Python
- pandas
- numpy

## How to Run
1. Install dependencies:
   pip install pandas numpy

2. Run:
   python data_cleaning.py

## Key Insights
- Cleaned dataset improves accuracy for analysis
- Loyalty status impacts average customer spending
- Certain product categories drive most revenue
- Customer purchase frequency varies significantly

## Purpose
Built to practice data cleaning, preprocessing, and generating business-ready datasets.
